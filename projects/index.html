Wearable Haptic Feedback System for Skill Reinforcement

Developed a battery-powered wearable feedback system around an ESP32-C3, custom PCB hardware, and an LRA haptic actuator. Implemented embedded C++ firmware for BLE configuration, I2C haptic-driver control, persistent actuator calibration, configurable feedback patterns, non-blocking timing, and deep-sleep power management. Integrated the wearable with a mobile application for wireless training configuration and control using Expo and Javascript.

Smart HVAC System for Microclimate Control

Developed an Arduino-based closed-loop microclimate controller using temperature feedback and PWM-controlled ventilation. Implemented proportional control with a temperature deadband and minimum fan-speed threshold, while providing real-time temperature monitoring and joystick-adjustable setpoints through an LCD interface.

Optical Heart Rate Sensor

Developed a four-stage non-invasive optical heart rate sensor using infrared photoplethysmography, cascaded active high-pass and low-pass filters, and comparator-based pulse detection. Frequency response analysis measured a 0.370–5.03 Hz passband with 54.87 V/V peak gain, while functional testing measured 90 BPM against a 93 BPM reference.

3-Band Audio Equalizer

Led, designed, constructed, and experimentally validated a three-band analog audio equalizer using passive RC filters, op-amp gain stages, signal recombination, and a power amplifier capable of driving an 8 Ω speaker. Verified frequency response from 100 Hz–10 kHz within ±2 dB across all bands.

555-Timer PWM LED Dimmer

Built, characterized, and tested a 555-timer PWM LED dimmer in astable mode with potentiometer control, achieving a controllable duty cycle range of approximately 11–97% at a fixed switching frequency. Verified monostable and astable timing behavior experimentally.
