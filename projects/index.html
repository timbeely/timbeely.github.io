Optical Heart Rate Sensor

2026
Analog Design Active Filters Op-Amps FRA Instrumentation

Developed a four-stage non-invasive optical heart rate sensor using infrared photoplethysmography, cascaded active high-pass and low-pass filters, and comparator-based pulse detection. Frequency response analysis measured a 0.370–5.03 Hz passband with 54.87 V/V peak gain, while functional testing measured 90 BPM against a 93 BPM reference.
