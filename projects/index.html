Wearable Haptic Feedback System for Skill Reinforcement

Developed an ESP32-C3-based wearable haptic feedback system integrating custom PCB hardware, rechargeable battery power management, embedded C++ firmware, I2C haptic control, Bluetooth Low Energy communication, and a React Native mobile application. Implemented non-blocking firmware and automatic LRA calibration to manage configurable feedback across multiple athlete wearables.

Smart HVAC System for Microclimate Control

Designed and implemented a closed-loop PID thermal regulation system using an Arduino, temperature sensor, motor driver, and DC ventilation fan. Developed the discrete PID controller in C++ to compensate for thermal response delay and minimize overshoot, stabilizing target temperatures within ±0.5 °C while providing real-time setpoint and system-state information through an LCD interface.

Optical Heart Rate Sensor

Developed a non-invasive optical heart rate sensor using infrared emitters, phototransistors, and op-amp signal conditioning to detect changes in capillary blood volume. Derived theoretical gain and cutoff-frequency behavior, then validated the circuit using frequency response analysis, oscilloscope measurements, and a physical LED output.

3-Band Audio Equalizer

Led, designed, constructed, and experimentally validated a three-band analog audio equalizer using passive RC filters, op-amp gain stages, signal recombination, and a power amplifier capable of driving an 8 Ω speaker. Verified frequency response from 100 Hz–10 kHz within ±2 dB across all bands.

555-Timer PWM LED Dimmer

Built, characterized, and tested a 555-timer PWM LED dimmer in astable mode with potentiometer control, achieving a controllable duty cycle range of approximately 11–97% at a fixed switching frequency. Verified monostable and astable timing behavior experimentally.
