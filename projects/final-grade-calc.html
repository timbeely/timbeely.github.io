Project Overview

I developed a client-side web application that helps students determine the score they need on a final exam to reach a desired course grade. The calculator supports courses with different grading structures, including weighted categories and individually weighted assignments.

The project was designed as a practical utility rather than a static calculator. Users can dynamically add or remove assignments, switch between weighting methods, include extra credit, and receive updated grade calculations without reloading the page.

Form data is saved locally in the browser so a user's course setup is restored after refreshing or reopening the application.

Key Visuals

Interactive Grade Calculation Interface

The application provides separate sections for homework, assignments, quizzes, and midterms while allowing each category to use either a shared category weight or individual assignment weights.

The interface also includes a responsive light/dark theme and a results panel that displays both the user's current class grade and required final exam score.

Technical Stack

  • Structure: HTML5
  • Styling: CSS3
  • Programming: JavaScript (ES6)
  • UI: Dynamic DOM generation and event-driven updates
  • Persistence: Browser Local Storage
  • Deployment: GitHub Pages
  • Features: Dynamic forms, validation, responsive design, and theme persistence

Engineering Approach

Dynamic User Interface

Rather than hard-coding a fixed number of assignments, I used JavaScript to generate course sections and assignment rows dynamically. Users can add or delete entries as needed, allowing the same application to support many different course structures.

Assignment labels are automatically renumbered after entries are removed so the interface remains organized as the form changes.

Flexible Weighting System

Each course category can operate in one of two weighting modes. Users can enter a single weight for an entire category or assign individual weights to each item within that category.

The interface updates automatically when the weighting mode changes, showing only the inputs required for the selected configuration.

Grade Calculation Logic

The application calculates how many weighted grade points have already been earned and determines the remaining score required on the final exam to reach the user's target grade.

The calculation also supports flat extra-credit percentages and reports the student's current course grade based on the portion of the course already completed.

Input Validation

I implemented validation to prevent invalid course configurations. Before producing a final result, the calculator verifies that the entered grading weights sum to exactly 100 percent.

The result interface also provides different messages when the required final score is above 100 percent, already mathematically secured, or within a normal achievable range.

Persistent Application State

Form state is serialized and stored in the browser using Local Storage. This includes target grades, assignment scores, weighting modes, category weights, and dynamically created assignment entries.

When the page loads, the stored configuration is reconstructed so users can continue where they left off instead of re-entering an entire course setup.

Responsive Theme System

The interface uses CSS variables to support both light and dark visual themes. Theme selection is also stored locally so the user's preference persists between sessions.

Key Takeaways

  • Built a complete interactive web application using HTML, CSS, and vanilla JavaScript.
  • Used dynamic DOM manipulation instead of relying on a fixed form structure.
  • Implemented application-state persistence using browser Local Storage.
  • Developed validation logic for multiple course-weighting formats and edge cases.
  • Strengthened my understanding of event-driven programming, UI state management, and client-side application design.
  • Deployed a functional utility application publicly using GitHub Pages.
